# Lab 03

A simple study system built with HTML, CSS, and JavaScript.

## Overview
This lab focuses on creating a student-friendly landing page with:
- a navigation bar
- a hero section
- a to-do list for study tasks
- resource links for academic subjects
- a contact form with validation
- a light/dark theme toggle

## Files
- `index.html` – main page layout and content
- `registeration.html` – registration page
- `style.css` – page styling
- `darkmode_registeration.css` – dark theme styling for registration page
- `script.js` – theme toggle and to-do list logic
- `validation.js` – form validation
- `01.png`, `02.png`, `03.png` – images used in the page

## Features
- Clean, modern UI
- Interactive study task manager
- Topic-based learning resources
- Contact form validation
- Theme switching for better readability

## Purpose
This lab helps practice front-end development concepts like DOM manipulation, form validation, and responsive page design.
