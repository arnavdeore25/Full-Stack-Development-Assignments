# Lab 05 & 06

A React-based study portal with login, theme toggling, quote display, and task management.

## Overview
This project is a front-end web application built using React and Vite. It includes a simple authenticated student dashboard with:

- login screen
- navigation bar
- hero section
- motivational quote component
- to-do list for academic tasks
- contact form
- footer
- dark mode toggle

## Tech Stack
- React
- Vite
- JavaScript
- Tailwind CSS
- ESLint

## Project Structure
- `src/App.jsx` – main app logic and login flow
- `src/components/` – reusable UI components
- `src/index.css` – global styling
- `public/` – static assets
- `index.html` – app entry point
- `vite.config.js` – Vite configuration
- `eslint.config.js` – linting rules

## Features
- User login simulation
- Conditional rendering after authentication
- Dark mode support
- Study task management
- Contact form section
- Responsive design


## Purpose
This lab focuses on React fundamentals, component-based UI development, state handling, and building a more complete front-end application.

Created as part of the Full Stack Development coursework.
