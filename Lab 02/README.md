# Lab 02

A small and simple single-page-application (SPA) built for a self-study platform using HTML, CSS, and JavaScript.

## Overview
This project demonstrates the basics of front-end web development, including:

- a landing section
- about and resource sections
- testimonials
- contact form
- dark/light theme toggle
- responsive layout styling

## Files
- `index.html` – page structure and content
- `style.css` – styling for the layout and theme
- `imageg/` – images used in the page

## Features
- Clean single-page design
- Navigation links for page sections
- Theme switch button using JavaScript
- Local storage to remember the selected theme
- Assignment-style student portal UI

## How to run
1. Open the `Lab 02` folder.
2. Open `index.html` in your browser.
3. Explore the page and the theme toggle.

## Purpose
This lab focuses on building a basic static web page and understanding how HTML, CSS, and JavaScript work together to create a functional user interface.
