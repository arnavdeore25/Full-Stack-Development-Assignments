# Lab 04

A study-focused landing page with a theme toggle, to-do list, and motivational quote feature.

## Overview
This project builds on the previous lab and adds more interactivity using JavaScript. The page includes:

- a responsive navigation bar
- a hero section for the learning platform
- a study task to-do list
- resource links for key subjects
- a contact form section
- a dark mode switch
- a random motivational quote displayed in the header

## Files
- `index.html` – main page layout and content
- `registeration.html` – registration page
- `style.css` – styling for the site
- `darkmode_registeration.css` – dark mode styling for the registration page
- `script.js` – theme toggle, task list logic, and quote loading
- `01.png`, `02.png`, `03.png` – images used in the page

## Features
- Dark/light theme toggle using local storage
- Add, complete, and delete tasks
- Persistent task storage in the browser
- Study resources section with external links
- Contact form with validation styling
- Dynamic quote from a public API

## Purpose
This lab focuses on improving front-end interactivity, JavaScript DOM manipulation, browser storage, and making a more dynamic student dashboard.


Created as part of the Full Stack Development coursework.
