# Self Study Dashboard

A simple Next.js-based self-study dashboard with a basic login system, home page, random quote API, and todo list.

## Features

* Object-based login authentication
* Login and logout functionality
* Random motivational quote fetched from an API
* Todo list for managing tasks
* Responsive and simple UI

## Technologies Used

* Next.js
* React
* TypeScript
* CSS
* REST API

## Note

This project uses object-based authentication and does not require a database. It is created as a frontend prototype for academic submission.
